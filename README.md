## 🚀 Running Locally

You can open `index.html` directly in any web browser, or start a lightweight local web server:

### Using Python:
```bash
python -m http.server 4321
```
Then visit: [http://localhost:4321](http://localhost:4321)

### Using Node / npx:
```bash
npx serve .
```

## 🌐 Free 1-Click Deployment

### Deploy to GitHub Pages:
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   ```
2. Create a repository on GitHub (e.g. `portfolio` or `dakshnimkar.github.io`).
3. Push to `main` branch.
4. Enable **GitHub Pages** under repository **Settings > Pages** selecting `main` branch root (`/`).

### Deploy to Vercel / Netlify:
- Simply drag and drop this folder into [app.netlify.com/drop](https://app.netlify.com/drop) or import from GitHub on [vercel.com](https://vercel.com).
